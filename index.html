团队技术手册 · 共享文档站

Python 代码

def fibonacci(n: int) -> list[int]:
    """生成前 n 项斐波那契数列"""
    seq = [0, 1]
    for _ in range(n - 2):
        seq.append(seq[-1] + seq[-2])
    return seq[:n]

if __name__ == "__main__":
    print(fibonacci(10))

如何添加内容

本站是单个 HTML 文件，所有内容都写在 index.html 里。用任意文本/代码编辑器（如 VS Code）打开即可编辑。

1. 打开文件

用 VS Code 打开 index.html。在文件中搜索 data-route="cat-env" 这类标记，就能定位到对应的分类页面。

2. 写入文字内容

在对应分类的 <section> 里，把"placeholder"占位块替换成你的手册文字即可。标题用 <h2>、段落用 <p>、列表用 <ul><li>。

html
<h2>安装步骤</h2>
<p>先克隆仓库，再安装依赖：</p>
<ul>
  <li>克隆仓库</li>
  <li>执行 npm install</li>
</ul>

3. 嵌入代码

复制下面的模板，把 language-xxx 改成对应语言（如 language-python、language-bash、language-json），中间填代码。

html
<div class="code-block">
  <div class="code-header"><span class="lang">bash</span><button class="copy-btn">复制</button></div>
  <pre><code class="language-bash">npm install</code></pre>
</div>

4. 嵌入图片

推荐把图片放进同目录的 images/ 文件夹，再用相对路径引用：

html
<figure>
  <img src="images/architecture.png" alt="架构图" />
  <figcaption>图 1 · 系统架构</figcaption>
</figure>

5. 嵌入视频

本地视频（放进 videos/ 文件夹）：

html
<div class="video-wrap">
  <video controls preload="metadata">
    <source src="videos/demo.mp4" type="video/mp4" />
  </video>
</div>

外部视频（B 站/YouTube 分享链接里的 src）：

html
<div class="video-wrap">
  <iframe src="外部视频嵌入地址" allowfullscreen></iframe>
</div>

6. 新增一个分类页面

若默认 4 个分类不够，可复制一个现有的 <section class="content" data-route="cat-xxx">…</section> 块，改 data-route 名称，再在左侧 <nav> 里加一条 <a class="nav-item" data-route="cat-xxx">新分类</a>。

7. 添加可下载文件

把文件放进 downloads/ 文件夹，然后在"资料下载"页复制下面模板，改文件名、大小、说明即可：

html
<div class="file-item">
  <span class="ficon">📄</span>
  <div class="fmeta">
    <div class="fname">接口手册.pdf</div>
    <div class="fdesc">团队内部接口说明</div>
  </div>
  <span class="fsize">2.3 MB</span>
  <a class="dl-btn" href="downloads/api-manual.pdf" download>下载</a>
</div>

图标可按类型替换：📄 文档、📦 压缩包、⚙️ 安装包、🎬 视频、🖼️ 图片。外链网盘文件把 href 换成网盘分享链接、去掉 download 即可。

改完后直接在浏览器刷新 index.html 即可看到效果，无需任何编译。

如何发布托管

把 index.html 发布到公网，团队就能通过网址访问。下面给两种免费、最常用的方式。

方式 A：GitHub Pages（推荐，长期维护）

1

注册 GitHub 并新建仓库

在 github.com 注册账号，新建一个公开仓库（如 team-docs）。

2

上传 index.html

把 index.html（连同 images/、videos/ 文件夹）上传到仓库根目录。可直接用 GitHub 网页"Add file → Upload files"。

3

开启 Pages

仓库 Settings → Pages → Source 选 main 分支 / / (root)，保存。稍等片刻会得到一个网址，形如 https://用户名.github.io/team-docs/。

4

分享网址

把这个网址发给你团队的成员，他们用浏览器打开即可浏览。

方式 B：Netlify（拖拽即发布，更快）

1

准备一个文件夹

把 index.html（和 images/、videos/）放进一个文件夹。

2

拖拽上传

访问 app.netlify.com/drop，把整个文件夹拖到页面里，几秒后会生成一个公网网址。

3

分享网址

可改一个简短的二级域名，再发给团队成员。

方式 C：公司内网服务器

如果手册含敏感信息、只能内网访问，把 index.html 及资源文件夹放到任意内网 Web 服务器（Nginx/Apache/IIS）的站点目录即可，成员用内网网址访问。

更新内容后：GitHub Pages 需重新提交文件；Netlify 拖拽方式需重新拖一次。建议内容稳定后再正式分享网址。

本地预览

发布前可先在本机预览：直接双击 index.html 用浏览器打开即可。视频/外链图片需联网。

关于本站

本站是一个轻量、免登录的团队共享技术文档站点，适合异地团队共享手册、代码、图片与视频。

设计理念

  • 够用就好：不依赖数据库、不依赖后端，一个文件就是整个站点。
  • 零门槛访问：成员不需要账号，浏览器打开网址即可看。
  • 易于维护：用 VS Code 之类的编辑器直接改 HTML，刷新即可见。
  • 可托管：随便放到 GitHub Pages、Netlify、内网服务器都能跑。
