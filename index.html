嵌入式端代码

涂鸦云 IoT 接入与米家插座的嵌入式端代码说明、依赖版本、功能点定义。

一、项目概述

本项目包含两个子项目的嵌入式端代码：

  • 涂鸦云 IoT 接入 — ECM50-A 工控机通过 MQTT 标准协议接入涂鸦云平台，上报冷库温度、湿度、运行模式和在线状态
  • 米家智能插座3 控制 — 通过 python-miio 库在局域网内读取/控制米家插座 (cuco.plug.v3)

二、运行环境要求

  • Python 3.8+（推荐 3.11）
  • pip 包管理器
  • 网络环境可访问 m1.tuyacn.com:8883（涂鸦 MQTT 服务器）
  • ECM50-A 工控机与 PC 在同一局域网（米家设备通信需要）

三、安装依赖

bash
# 涂鸦云项目依赖
pip install paho-mqtt

# 米家插座项目依赖
pip install python-miio python-dotenv

# 一次性安装所有依赖
pip install -r requirements.txt

四、涂鸦云设备凭证

在涂鸦 IoT 开发平台创建设备后获取以下凭证：

text
ProductID    : deihosbfawqqi8ac
DeviceID      : 263c9d32705d72a956qrgj
DeviceSecret  : SnZ9FfQ3zZODjr6e
MQTT Broker   : m1.tuyacn.com (中国数据中心)
MQTT Port     : 8883 (TLS 加密)

MQTT 连接三元组（Client ID / Username / Password）通过 HMAC-SHA256 动态计算，运行 python tuya_mqtt_auth.py 可查看生成结果。

五、涂鸦功能点定义

在涂鸦平台自定义的 4 个功能点：

  • DP108 cold_storage_temp — 冷库温度 (°C)，数值型，只上报，范围 -100~100
  • DP109 cold_storage_humidity — 冷库湿度 (%RH)，数值型，只上报，范围 0-100
  • DP110 cold_storage_run_mode — 运行模式，枚举型，可下发可上报，0=制热/1=制冷/2=除霜
  • DP111 ECM50A_online — 网关在线状态，布尔型，只上报

六、启动数据模拟器（供前端测试）

模拟器会每 5 秒上报一次模拟冷库数据到涂鸦云，断线自动重连，适合长时间挂机运行：

bash
python tuya_simulator.py

运行后可在涂鸦 IoT 平台 → 设备管理 → 设备日志中查看实时上报数据，或在前端页面看到设备状态变化。

七、PC 端 MQTT 连接测试

先在 PC 上验证 MQTT 连接是否正常：

bash
# 验证 MQTT 参数计算
python tuya_mqtt_auth.py

# 测试连接和数据上报
python test_tuya_mqtt.py

八、米家插座代码说明

通过 python-miio 库在局域网内读取/控制米家智能插座3：

bash
# 1. 配置 .env 文件
cp .env.example .env
# 编辑 .env，填入设备 IP 和 Token

# 2. 运行示例程序
python main.py

Token 获取方式：使用 Xiaomi-cloud-tokens-extractor 工具从小米云端提取。
